This repository contains the supplementary material accompanying the article entitled "Refactoring-based-Optimization-of-Business-Process-Models".
More precisely, it contains:
- a "TOOL" directory, containing the source code of the Java tool used to perform the experiments referenced in the article
- an "EXPERIMENTS" directory, containing the experiments shown in the article
- a "COMPANION" directory, containing a PDF file providing (among others) the proofs of the theorems introduced in the article
